# 小红书 AI 工作台研究站设计契约

- Entry mode: brief-led implementation
- Request revision: 2 — 根据实际理解反馈，把核心定位从“内容参谋”进一步收敛为“方法论与策划模板”，明确不提供可直接发布的成品，也不判断小红书是否值得投入。
- Target user and context: 0805 GitHub Code Study 的研究者与读者，需要判断该仓库能做什么、如何工作、是否值得采用，并看到它怎样服务现有研究产品。
- Desired first impression: 一眼看懂“它给方法，不给成品”：这是一套可检查的小红书策划模板，不是内容生产、价值验证或代运营后台。
- Visual ambition: Editorial
- Experience architecture: Editorial Flow
- Visual constraints: 使用小红书式红色作为有限强调，配合纸张白、深墨色和研究标注色；避免仿制小红书官方界面、手机壳堆叠、营销渐变和无意义动画。
- Information constraints: 区分上游事实、研究判断和确定性演示；能力、步骤和边界链接到固定上游文件；不把浏览器演示描述成实时调用模型或平台。
- Operation constraints: 纯静态 HTML/CSS/JavaScript，无后端、无登录、无小红书 API、无自动发布；演示数据内置并来自一份实际应用记录。
- State constraints: 能力模块选择、工作流步骤切换、运行进度、策划样例输出、事实/判断标签、复制反馈和重新运行必须可理解。
- Environment constraints: 接入既有 GitHub Pages 多项目结构；桌面 1440px、平板 768px、手机 390px；中文界面；键盘可操作；尊重 reduced-motion；本次只支持浅色主题。
- Primary journey: 进入页面先看懂“它给什么 / 不给什么” → 查看七个 Skills 的方法与路由 → 运行“0805 GitHub Code Study”策划样例 → 看到上游能力停在主页、母题、日历、标题、评论和路径 → 明确完整正文、图片、发布与数据复盘仍需自己或其他工具完成。
- User-defined phases: 获取上游库；整理能力；演示能力；结合现有产品实际使用一个样例。
- Required artifacts: 固定版本 upstream；来源锁定记录；研究结论；完整策划样例；可运行交互站；设计契约；覆盖清单；浏览器验收；交接说明；根 README 与发布配置。
- Autonomy authorization: 用户已明确要求把该库作为下一研究项目并完成获取、研究、演示和策划样例，可在当前仓库内直接实施可逆变更。
- User-decision boundary: 安装到用户全局 Codex、接入真实小红书账号/API、外部发布、发送消息、付费服务或修改上游仓库需要另行授权。
- Observable completion criteria: 本地保存可追溯上游版本；研究文档明确它是方法论与策划模板、不会判断是否值得做；网页首屏和样例区都明确“不是可发布成品”；六段流程显示上游实际交付与后续缺口；1440/390 无关键遮挡或页面级横向溢出；核心流程键盘可达；构建和语法检查通过；只提交本项目与根导航到远端 main。

## 第 2 版信息修订

- 首屏主结论改为“给你方法，不给你成品”。
- 新增“它交付什么 / 你仍要做什么”的同屏对照。
- 明确它不回答“小红书值不值得投入”，只在用户已经决定运营后提供策划流程。
- 将实际样例统一标记为“策划输出”，不再让“实际样例”被误解为可直接发布的完整笔记。
- 采用判断收敛为：对内容策划有用；单独作为小红书生产工具价值有限；更适合作为自有 Skill 的结构参考。


## 设计方向

| 决策 | 选择 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 信息层级 | 结论 → 能力地图 → 策划运行 → 采用判断 | 首屏同时回答“是什么、不是什​​么、下一步看什么” | 第一次扫描不会误解为自动运营软件 |
| 主视觉 | 编辑桌与研究批注，不复刻平台 UI | 纸张、装订线、状态戳用于解释层级 | 内容信息始终比装饰更突出 |
| 交互模型 | 六段工作流播放器 + 输出检查台 | 每一步均显示输入、规则、产物和来源 | 键盘和鼠标都能完整检查样例 |
| 状态反馈 | 文本状态、进度、选中态与 aria-live | 运行、完成、复制失败都不能无声 | 用户始终知道当前步骤和数据性质 |
| 响应式 | 桌面主从双栏，窄屏连续单栏 | 手机上工作流导航可换行，不依赖横向拖动 | 390px 完整阅读与操作，无页面级溢出 |
| 动效 | 只解释运行和步骤切换 | reduced-motion 下关闭位移和逐步延迟 | 关闭动效不丢失任何结果 |
