# The Long Silence · 飞船能力提炼 Demo

这是对 [achimala/TheLongSilence](https://github.com/achimala/TheLongSilence) 的能力提炼，不是整套游戏复刻。Demo 把上游最有迁移价值的生成、尺度、飞船语言、内外空间呼应与可观测性，整理成一个可操作、可比较的浏览器场景。

## 当前研究状态

本阶段已于 **2026-08-06 暂时归档**。当前结论、已接入范围、验证证据、明确边界和下次恢复入口，统一整理在 [阶段归档：First Canto 垂直切片](./research/archive/2026-08-06-first-canto.md)；研究文档导航见 [research/README.md](./research/README.md)。现有 Demo 保持可运行，不再进行无明确研究问题的功能扩张。

## 故事与当前切片

四万年前，八十光年内的九百个有人世界在四天内全部沉默。没有残骸、辐射或战争痕迹；城市仍亮着，轨道仍整齐，档案仍开放。Choir 只留下七台分散在七个星系中的共鸣器。玩家驾驶 `Pale Seeker` 进入沉默区，扫描世界、定位共鸣器，并从每台共鸣器取回一段 `Canto`。

当前 Demo 诚实地只实现其中第一段：扫描 ITHIRKA II → 发现没有灾难痕迹与持续四万年的共鸣信号 → 追踪 `RESONATOR I` → 完成调谐 → 解锁 `THE FIRST CANTO · 1/7`。这段故事被绑定到 HUD、目标遥测、操作按钮和任务简报，而不是只作为页面背景介绍。

## 运行

```bash
npm install
npm run dev
```

打开 Vite 输出的地址，建议使用支持 WebGL2 的浏览器。本次工作区固定使用 `http://127.0.0.1:5180/`。

能力降级可以用 `http://127.0.0.1:5180/?webgl=off` 确定性复现；该参数与真实 WebGL2 探测失败共用同一产品路径，但不假装测试设备真的缺少 GPU。

## 建议体验顺序

1. 点击场景获得键盘焦点，用 `W/S` 推进或后退、`A/D` 转向；手机持续按住舞台上的五个驾驶按钮。
2. 进入 `2.65u` 扫描距离后按 `Space` 或“制动”，把速度降到 `0.30u/s` 以下；首次扫描完成后点击“追踪共鸣器”，根据实时左右角度转向，再推进并完成调谐。
3. 再播放 20 秒导览，看轮廓、材料、驾驶舱、扫描和相对原点如何自动串联；导览会使用确定性自动进近，不替代手动任务。
4. 在“资产保真度”中切到“源库高保真”，观察 11 个内舱文件的真实完成进度，再用同一套驾驶和任务状态比较外部船体与真实内舱。
5. 用 Auto / Detail / Eco 切换渲染预算，最后阅读“真实覆盖”和“沉淀笔记”，区分已接入、概念演示与后续路线。

驾驶时镜头自动平滑追随；停止输入后仍可拖拽观察，侧栏“重置飞行取景”可恢复追随构图。按 `V` 切换外部/驾驶舱；拖动镜头、按 `Esc` 或点击任一场景操作均可中断导览。

## 当前实现

- 玩法/视觉分层：飞船、调查目标、碰撞与扫描继续使用稳定的 XZ 任务平面；四个非任务轨道按 seed 生成倾角和升交点，以三维纵深增强宇宙尺度感，不把操作升级为六自由度飞行。
- 确定性第一段 Canto：首次扫描会揭示同 seed 派生的共鸣器；玩家需要主动追踪、按实时方位提示转向、再次推进和调谐，最终取回 `CANTO 1/7`。
- 固定种子生成：同一 seed 生成同一组恒星、行星、轨道、颜色与目标数据。
- 双层 3D 场景：宇宙作为持续背景，驾驶舱作为独立前景叠加渲染。
- 轻量提炼模式：用程序化几何解释轮廓、材料分工、居住证据和状态反馈，默认不加载高保真资产。
- 源库高保真模式：按需调用上游 `buildHull` 船体生成器，并加载 Draco 内舱、AO 与 albedo/normal/ORM 烘焙材质。
- 真实加载反馈：模块阶段与 11 个内舱文件的完成事件驱动同一条进度；失败时保留轻量版并允许重试。
- 自适应画质：Auto / Detail / Eco 直接改变 renderer 像素比；Auto 使用持续帧率采样、滞回和冷却避免频繁跳档。
- 源库船体几何 LOD：近景保留完整 `buildHull`，远景切到 248 tris 的轮廓代理；两个距离阈值避免来回闪烁。
- 最小驾驶闭环：单一 XZ 平面上的推进、后退、转向、惯性、制动和简化行星安全边界；真实位置和朝向同时驱动镜头、距离、引擎与扫描条件。
- 任务门槛：两个目标都只有在距离不超过 `2.65u` 且速度不超过 `0.30u/s` 时才能扫描；发现、转向、远距离、高速、扫描中、最终完成和碰撞均有不同反馈。
- 双输入与追随镜头：桌面支持 `W/S/A/D/Space`，移动端提供五个持续按压按钮；驾驶时平滑追随，停止后恢复自由观察，驾驶舱按船头方向观看。
- 可读 WebGL 降级：3D 不可用时显示静态飞船结构示意，保留研究说明和来源，安全禁用 3D 操作，并提供重新检测入口。
- 共享任务状态：两种资产模式都支持第一段 Canto 任务、外部/内舱切换、条件扫描、折跃、重置、重生成及 20 秒导览。
- 相对原点概念演示：折跃后把巨大世界坐标转换为接近观察者的小型渲染坐标。
- 运行证据：FPS、draw calls、三角形和像素比例直接来自当前 Three.js renderer。
- 响应式与键盘：桌面和 375px 窄屏均可完成驾驶与扫描；场景可获得键盘焦点，`V` 可切换视角，焦点样式可见。

## 资产与许可边界

高保真模式复用上游的程序化船体实现，以及 11 个真实内舱文件，共约 3.79 MiB。它们只在用户主动选择“源库高保真”后加载。4 个本 Demo 不使用的地形纹理没有复制进来。

上游代码与资产按 MIT License 使用，完整声明见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。开发构建时需要相邻目录 `../the-long-silence` 中的上游源码；生产构建会把相关模块打包成独立的按需 chunk。

“L2/L3”表示这套资产已经足以进行近景结构和材质研究，但不代表商业成片质量。当前驾驶是用于验证任务闭环的单平面模型，不是六自由度模拟；尚未接入行星烘焙、完整后处理和着陆系统，页面中的覆盖矩阵会诚实标注这些边界。

## 性能策略

- 高保真资产使用动态 import，不增加默认首屏的 3.79 MiB 模型与纹理传输。
- 自动画质的 DPR 档位为 Eco 0.85、Balanced 1.10、Detail 1.35，并受设备实际 DPR 上限约束。连续 4 个半秒采样低于 48 FPS 才降档，恢复需连续 16 个采样高于 57 FPS；每次变化后冷却 6 秒。
- 高保真内舱的阴影在进入模式时生成一次，运行时冻结复用；当前验证中扫描状态从重复更新时约 296 draws 降到约 54 draws。
- 高保真外部船体在 12.5 个场景单位外使用远景代理，10.8 内恢复完整船体。桌面实测从近景约 `33 draws / 150k tris` 降到远景约 `15 draws / 13k tris`；这是场景单位，不伪称真实米制。
- 当前环境观测约为：高保真外部 31 draws，高保真内舱扫描 54 draws；轻量内舱约 34 draws。数值随 GPU、窗口与裁剪变化，不作为固定承诺。
- 主入口仍包含 Three.js，Vite 会提示主 chunk 超过 500KB；生产化的下一步应继续拆分 3D 核心或改为进入体验后再加载。

## 验证记录

- `npm run build` 通过。
- 构建产物中源库船体、内舱和环境模块保持独立按需 chunk；主入口约 680.10 KiB（gzip 179.24 KiB）。
- 桌面已完成“扫描 ITHIRKA II → 发现共鸣器 → 转向 → 推进 → 制动 → 调谐 → CANTO 1/7”；移动端触控覆盖第二航段的转向和推进。
- 桌面与 375 × 844 移动视口均无横向溢出。
- 两种资产模式可往返切换；高保真外部和 Draco 驾驶舱继续服从驾驶、扫描、重生成和导览状态。
- `npm run test:visual` 会自行启动临时 Vite 服务，通过本机 Edge/Chrome 比较 desktop/mobile × study/fallback 四张基线；超过 1% 像素差异时失败并输出 diff。
- 确认有意的视觉变化后，运行 `npm run test:visual:update` 更新基线，再重新执行普通视觉测试。
- 浏览器错误日志为空。
- 详细记录见 [research/browser-evidence.md](./research/browser-evidence.md) 与 [research/coverage-manifest.md](./research/coverage-manifest.md)。

## 已知边界

- `?webgl=off` 已证明降级产品路径可运行；仍建议在真实 GPU 黑名单、驱动故障或完全禁用 WebGL2 的设备上做硬件矩阵复测。
- 自动视觉回归会以 reduced-motion 启动浏览器并覆盖静态布局，但尚未自动执行 reduced-motion 下的完整扫描与折跃时间线。
