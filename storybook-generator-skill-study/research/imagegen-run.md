# ImageGen 完整样书实验 · Run 001

## 目标

把上游 Skill 的“角色圣经 → 逐页 Prompt → QA → 局部返工”从文字说明推进到一整本可翻阅、可定位问题的真实图片实验。

## 生成方式

1. 使用 Codex 内置 ImageGen 生成角色锚点图；
2. 封面和 8 张内页均显式引用该锚点图；
3. 每页固定 4:3 横版、无文字、同一角色外观、黄色睡衣、深蓝拖鞋、兔子灯和深青色卧室；
4. 每页只改变一个叙事动作，正文仍由网页单独排版；
5. 网页加载已生成 PNG，避免把“浏览器装配”误称为实时模型调用。

## 局部返工记录

初版检查发现第 6—8 页的图文或光影因果不够成立，因此没有接受“看起来像”这一结果，而是保留 v1 后逐页重生成：

- 第 6 页：把“椅子上的熊脸物体”改成真正挂在墙钩上的可穿戴熊帽；
- 第 7 页：把鞋子从灯旁地面移到灯—墙光路中，生成对应鞋形投影；
- 第 8 页：让枝叶位于窗外，豆豆双手留在被子上，禁止手形影子成为来源。

## 研究结论

参考图能够解决大部分“同一个人”的问题，但不能单独解决“同一个道具”和“同一个因果关系”。这次 v1→v2 的局部返工说明：结构化光影契约可以帮助发现问题，也能把重生成范围缩小到失败页。因此下一步最有价值的研究不是继续堆叠描述词，而是：

```text
角色锚点 + 道具锚点 + 场景锚点
→ 逐页引用与状态继承
→ 视觉相似度 / 图文证据评分
→ 只重生成失败页面
```

## 产品边界

当前网页是静态研究播放器和分析器，不在浏览器端实时调用 ImageGen。实际图片生成由 Codex 在研究运行中完成，再作为可审计资产接入网页。其他主题或 12/16 页组合会显示“代码插画 · 回退模式”，避免制造已调用模型的错觉。
