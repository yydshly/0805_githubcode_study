        04 / 真实生成对照

        Prompt 变长不等于变好；真正变化的是控制权

        同一个“雾岭青梅气泡茶”任务，分别用短 Prompt、库的六段模板、带执行检查的 Skill Prompt 各生成一次。以下是一次样本的人工观察，不是模型能力的科学因果结论。

        固定任务产品名、标题、3 个卖点、3:4 小红书首图
        唯一变化Prompt 的结构、约束和检查方式
        观察维度文字 · 布局 · 风格 · 约束
        LEVEL 1短 Prompt一句需求
        文字准确3/53
        布局控制2/52
        风格匹配2/52
        约束遵循2/52

        观察：标题醒目，但模型自行改成塑料瓶、增加英文和额外文案；“想要什么”清楚，“不要什么”缺失。

        查看这档输入
        帮我为“雾岭青梅气泡茶”做一张小红书新品宣传图，3:4 竖版，标题是“一口醒夏”，卖点是“0 糖、真果汁、冰爽气泡”。
        LEVEL 2六段模板库的核心能力
        文字准确5/55
        布局控制5/55
        风格匹配5/55
        约束遵循4/54

        观察：画幅、单罐、技术图风格、主标题、产品名和三个卖点均命中；仍出现未定义编号标注，说明模板不能消除模型自由发挥。

        查看这档输入结构
        主体与任务 → 构图与布局 → 视觉风格与材质 → 文字与标签 → 比例与输出 → 限制与负面项
        LEVEL 3Skill Prompt模板 + 执行检查
        文字准确4/54
        布局控制5/55
        风格匹配5/55
        约束遵循3/53

        观察：执行目标和版式稳定，但模型又发明了“≥12%”“100%”“330 毫升”等数据；Skill 的价值是路由和复核，不是保证第一次生成必然正确。

        查看这档新增控制
        用途分类 + 资产位置 + 精确文字 + 布局坐标 + 不变量 + 禁止项 + 生成后检查顺序
        结论

        库最能提高的是“需求完整性和可复查性”。模板让第一次结果更接近目标；Skill 进一步帮助自动选模板、追问缺失字段和检查失败项。文字与数据仍必须人工复核，失败时应只修改一个变量再生成。

        YOUR STARTING ROUTE

        从“商品商业视觉”模板开始

        先锁定包装识别和准确文案，再加入环境与道具。第一次只生成一个明确成品，不要同时要求主图、详情页和包装展开图。

        第一动作
        写出产品名、3 个卖点、唯一主标题、渠道和画幅。
        重点约束
        指定文字必须逐字显示，禁止随机英文、占位文本和改写品牌名。
        评估方法
        先检查商品识别和文字，再评价“好不好看”。失败时只修改一个变量。
        可交给 Agent 的起始请求

        使用 gpt-image-2-style-library，为我的商品主图选择模板。先向我确认产品、渠道、文案、画幅和必须避免的错误，再输出自然语言 Prompt 与 JSON 版本。

        LEVEL 1

        找案例，手动改

        适合一次性任务。先复制结构，再替换业务变量；不要只抄风格词。

        成本最低 · 一致性一般
        LEVEL 2

        固定模板，批量变体

        适合社媒与电商。固定版式和品牌约束，只变化主体、场景、色板。

        可复用 · 需要评审规则
        LEVEL 3

        Skill + 自动化

        适合多类需求。让 Agent 选模板和补字段，再由模型适配器负责调用。

        可扩展 · 需要测试集

        READ BEFORE APPLYING

        四条边界，决定你会不会用错

        • 模板提高完整性，不提高模型上限。文字准确、人物一致和细节质量仍由底层模型决定。
        • 好案例不等于稳定复现。案例库有幸存者偏差，正式使用要做多次对照生成。
        • MIT 不覆盖所有案例素材。第三方图片与 Prompt 的商业授权需要回到原始来源确认。
        • 展示能力不等于网站接口能力。研究快照中有 2 条 Prompt 超过在线接口的 6000 字符限制。
