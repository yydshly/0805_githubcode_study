# Storybook Generator Skill 研究站设计契约

- Entry mode: brief-led
- Request revision: 3 — 在完整绘本实验台中加入逐页光影因果 QA。
- Target user and context: 内部研究者与产品开发者，需要快速理解上游 Skill 的能力、机制、边界和可复用价值。
- Desired first impression: 一座温暖、严谨的“绘本生产实验室”，既有编辑感，也清楚区分上游事实与本项目模拟。
- Visual ambition: Editorial
- Experience architecture: Hybrid Workspace
- Visual constraints: 纸张与油墨语义、暖色强调、清晰层级；避免儿童化玩具 UI、过量渐变和无意义动画。
- Information constraints: 所有能力结论必须可追溯到上游文件；默认样书使用已生成的 ImageGen Run 001 资产，浏览器只负责装配和分析，不宣称运行时调用模型。
- Operation constraints: 纯静态站点、无后端、无登录；内置完整研究样书和确定性故事编译器；可直接部署到 GitHub Pages。运行时不伪装成在线图片模型调用。
- State constraints: 提供项目输入、整本生成进度、完成态、翻页态、页缩略图选择态、逐页 Prompt、光源—遮挡物—投影面契约、跨页一致性分析与问题标记。
- Environment constraints: 桌面、平板和 390px 手机；中文界面；支持键盘；尊重 reduced-motion；本次只支持浅色主题。
- Primary journey: 输入故事概念并设置年龄/页数/语言，点击“生成完整绘本”，看到全书生成进度；完成后进入持续可见的绘本舞台，翻阅封面与所有内页，并在相邻分析面板查看本页正文、Prompt、视觉锚点、光影契约、图文契约和跨页一致性问题。
- User-defined phases: 获取项目；研究能力；以 Web 方式控制生成一部完整绘本；对成书进行逐页和跨页分析。
- Required artifacts: 固定版本的 upstream；完整研究样书（封面 + 8 页内页）；完整页数据与逐页 Prompt；生成控制器；翻页阅读器；一致性与光影分析台；研究说明；浏览器验收记录；根项目导航配置。
- Autonomy authorization: 用户已明确要求作为新子项目研究并用 Web 展示，可在上述范围内直接实现和验证。
- User-decision boundary: 接入真实图片模型、后端、登录、付费服务、对外发布或修改上游仓库需要另行授权。
- Observable completion criteria: 点击生成后形成至少“封面 + 8 页内页”的完整绘本；可以顺序翻页和从缩略图跳页；每页有插画、正文、角色锚点、图文契约、光影契约和 Prompt；可以查看全书一致性总分、光影复查页及逐页问题；桌面/手机核心旅程无关键遮挡；交互可键盘触达；构建检查通过；来源链接清晰。

## Hybrid Workspace 约束

- 持续舞台：当前绘本页面、页码、上一页/下一页和全书缩略图。
- 详情区域：当前页正文、Prompt、图文契约、一致性维度和返工建议。
- 状态映射：未生成时显示简报；生成中显示九步生产进度并建立光影契约；完成后同时激活绘本舞台与分析面板；问题页在缩略图、当前页和光影 QA 面板同时标记。
- 移动端转换：绘本舞台优先，分析详情位于其下方；不依赖悬浮面板完成核心旅程。
- 降级：无生成图资产时仍以代码原生插画和完整文本保证整本书可读、可分析。

## 设计方向

| 决策 | 方向 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 信息层级 | 先给结论，再进入交互式流水线，最后呈现研究判断 | 首屏同时出现项目定义、能力边界和主操作入口 | 用户无需阅读全文即可知道它不是生图模型 |
| 视觉语言 | 编辑工作台：奶油纸、深墨色、珊瑚红与鼠尾草绿 | 装饰不替代信息，不使用厚重拟物 | 控件与研究内容边界清楚 |
| 交互模型 | 表单生成确定性蓝图，步骤导航驱动内容切换 | 每个按钮都有明确状态和文本反馈 | 不依赖鼠标即可完成核心旅程 |
| 响应式 | 宽屏双栏，窄屏单栏；步骤条可横向滚动 | 390px 不出现页面横向溢出 | 主操作和结果在手机上仍按阅读顺序出现 |
| 动效 | 仅用于状态切换和结果进入 | reduced-motion 下关闭位移与平滑滚动 | 动效关闭不损失信息 |
